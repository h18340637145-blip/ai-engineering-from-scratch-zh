# 产品说明：从零构建 AI 工程

## 一句话定位

这是一个免费、开源、以可运行实现为中心的 AI 工程课程库。它将 AI 学习路径组织为 20 个递进阶段和 503 节课程，覆盖从数学基础到生产系统与综合项目的完整链路。

## 目标用户

- 已具备基础编程能力，希望理解 AI 原理而不只调用 API 的学习者。
- 需要补齐算法、LLM、Agent、基础设施知识链路的工程师。
- 希望获得可复用提示词、技能或 Agent 产物的实践者。
- 维护课程内容、网站和发布流程的开源贡献者。

## 核心问题

AI 学习资料常按论文、教程或工具分散存在。学习者可能能拼出一个演示，却无法解释损失函数、注意力机制或 Agent 循环的工作原理。本项目通过一条显式的先修路径和统一课程契约，将概念、手写实现、框架用法、测试与可交付工具连成闭环。

## 产品原则

1. **从原理到工程。** 先用原始数学和小型实现构建算法，再使用生产框架对应同一操作。
2. **内容可运行。** 每节课至少包含叙述文档和代码；课程质量由自动审计检查基本不变量。
3. **学习产出可复用。** 课程可附带 prompt、skill、agent 或 MCP server 等产物，而非只停留在知识讲解。
4. **同一事实源，多种阅读入口。** 课程目录驱动仓库阅读、静态网站、技能安装和书籍发布。
5. **本地优先，开放协作。** 内容可克隆后在本地运行，MIT 许可允许学习、复用与贡献。

## 课程体验

学习主路径从环境与数学基础开始，经过机器学习、深度学习、视觉、NLP、Transformer 和生成式 AI，继续到 LLM、工具协议、Agent、基础设施、安全与综合项目。README 中的阶段图表达推荐依赖关系；ROADMAP 记录每阶段及每课的完成状态。

每个课程目录通常遵循以下结构：

```text
phases/<阶段>/<课程>/
├── docs/en.md       # 课程叙述与学习目标
├── code/            # 可运行实现与测试
├── quiz.json        # 浏览器可用的测验（存在时）
└── outputs/         # 可安装或复用的课程产物（存在时）
```

课程叙事采用 "Build It / Use It"：先实现核心机制，再用框架或生产库验证其等价用途，最后把经验沉淀为工具型产物。

## 交付形态

| 形态 | 面向的需求 | 来源 |
|---|---|---|
| Git 仓库 | 阅读、运行、贡献与审查全部课程素材 | `phases/`、根目录索引与脚本 |
| 静态网站 | 课程浏览、搜索、术语、先修路径和本地学习进度 | `site/` |
| 可安装产物 | 将课程中沉淀的技能、提示词等带入日常 Agent 工作流 | 各课 `outputs/` |
| EPUB/PDF 图书 | 离线或顺序阅读的六卷快照 | `book/` 与 `scripts/build_book.py` |

## 当前规模与边界

截至 2026-08-06，以 `python3 scripts/build_catalog.py --stdout` 的目录扫描结果为准：20 个阶段、503 节课程、744 个代码文件、388 个技能、99 个提示词；当前没有被目录扫描识别为 `agent-*` 的课程 Agent 产物。

项目是课程与工具产物仓库，不是在线模型服务或 SaaS。站点为静态前端，学习进度仅保存在访问者浏览器的 `localStorage` 中，不涉及账户、服务器端进度或用户数据同步。

## 成功标准

- 学习者能沿先修关系找到合适起点，并独立运行和修改课程实现。
- 每节新增或修改的课程保持文档、代码、测验和产物之间的一致性。
- 站点、技能安装器与图书构建都能从同一课程目录稳定派生。
- 贡献者能用仓库脚本及 CI 在合并前发现结构、链接和计数问题。
