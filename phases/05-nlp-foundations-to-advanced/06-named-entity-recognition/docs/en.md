# 命名实体识别（Named Entity Recognition - NER）

> 从非结构化文本中抽取人名、地名、组织机构与实体：序列标注模型。

**Type:** Learn / Build
**Languages:** Python
**Prerequisites:** Phase 5 Lessons 1-3
**Time:** ~60 分钟

## 学习目标

- 理解 BIO / BILOU 序列标注规范
- 构建基于 BiLSTM-CRF（双向 LSTM 与条件随机场）的实体识别模型
- 评价 NER 任务的 Strict 与 Partial 实体匹配指标
