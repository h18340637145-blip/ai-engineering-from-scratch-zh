# 词袋模型与 TF-IDF（Bag of Words & TF-IDF）

> 统计词频与逆文档频率：经典频次统计型文本向量化方案。

**Type:** Learn / Build
**Languages:** Python
**Prerequisites:** Phase 5 Lesson 1
**Time:** ~60 分钟

## 学习目标

- 从零实现词袋模型（Bag-of-Words, BoW）与稀疏矩阵表征
- 理解词频（TF）、逆文档频率（IDF）与 TF-IDF 权重的数学公式
- 分析 TF-IDF 在信息检索（IR）与传统文本分类中的应用
- 探讨词袋模型忽略词序（Word Order）的局限性
