# 文本预处理基础（Text Processing Fundamentals）

> 计算机处理的是数字，而不是文本。清理、分词与规范化是将原始文本转化为机器学习输入的关键一步。

**Type:** Learn / Build
**Languages:** Python
**Prerequisites:** Phase 1 Lesson 1（向量与矩阵）
**Time:** ~45 分钟

## 学习目标

- 掌握文本清理、大小写转换、标点符号移除与正则表达式文本提取
- 理解词干提取（Stemming，如 Porter Stemmer）与词形还原（Lemmatization）的差异
- 掌握 N-gram 切分（Unigram, Bigram, Trigram）及其文本语言特征建模原理
- 使用 Python 纯手写与 NLTK/spaCy 实现预处理管道
