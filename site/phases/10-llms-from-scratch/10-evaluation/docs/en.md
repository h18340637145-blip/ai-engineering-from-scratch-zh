# LLM 基准评估（LLM Evaluation & Benchmarks）

> 如何科学地评价一个大模型：从 MMLU、GSM8K 到 HumanEval。

**Type:** Learn / Build
**Languages:** Python
**Prerequisites:** Phase 10 Lesson 4-8
**Time:** ~60 分钟

## 学习目标

- 了解学术界与工业界核心基准测试（MMLU, GSM8K, HumanEval, ARC, MATH）的构建方法
- 实现多项选择题与代码执行型 Benchmark 的评测 Harness
- 理解 Logit 似然度评估与采样生成评估的差异
- 掌握评测中的数据污染（Data Contamination）识别与防范
