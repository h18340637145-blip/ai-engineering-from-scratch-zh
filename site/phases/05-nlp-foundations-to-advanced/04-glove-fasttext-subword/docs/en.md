# GloVe 与 FastText 向量（GloVe & FastText）

> 全局共现矩阵矩阵分解与基于子词（Subword n-grams）的未登录词表示。

**Type:** Learn / Build
**Languages:** Python
**Prerequisites:** Phase 5 Lesson 3
**Time:** ~60 分钟

## 学习目标

- 理解 GloVe（Global Vectors for Word Representation）通过对共现矩阵进行对数双线性回归的原理
- 掌握 FastText 利用字符级 N-gram 子词构建词向量的方法
- 解决未登录词（OOV - Out of Vocabulary）问题与形态丰富语言的向量化表示
